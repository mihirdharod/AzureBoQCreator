# Tests

```bash
pip install openpyxl
python tests/run_tests.py
```

123 assertions, no network, no browser, no customer data. Exits non-zero on
failure.

## Fixtures

`tests/fixtures/*.xlsx` are generated by `make_fixtures.py` and are entirely
synthetic. They deliberately reproduce the messy shapes real inventories arrive
in, because those are what the parsers have to survive:

- every sheet names its columns differently
- storage written as `1.1TB`, `610GB`, `2 TB - Premium SSD Managed Disks`, `?`
- non-breaking spaces and stray whitespace inside cells
- a sheet with no OS column at all
- a trailing `Note:` row that is not a server
- an exported estimate whose `Total` label sits in the **Region** column, with
  shared services carrying a blank Custom name

Regenerate with `python tests/make_fixtures.py`.

## What is covered

| Area | Checks |
|---|---|
| `parse_inventory.py` | fuzzy header matching, storage/unit parsing, OS inference, peer-median inference for `?`, sheet exclusion, disk tiering, and that it **refuses** a workbook with no SKU column rather than inventing one |
| `size_from_source.py` | rightsize vs lift, `8.79TB` / `755 GB` / `150G` / `64 Lcpu` parsing, every recommended SKU actually meets its target, plan matches the harness contract |
| `build_summary.py` | Total-row detection, unnamed shared services, category rollup, arithmetic, idempotency, static values rather than cross-sheet formulas |
| `harness.js` | parses as valid JavaScript, exports its full API |
| docs | frontmatter valid, every reference file exists and is linked, failure modes numbered contiguously, the count quoted in `SKILL.md` is accurate |
| hygiene | no customer hostnames, GUIDs or credentials anywhere in the repo, including inside the fixture workbooks |

Several assertions are regression guards for specific bugs found while building
real estimates, so a fix cannot silently be undone:

- an unnamed shared service being dropped from the summary
- the phantom empty `.wa-calcService` row on a fresh calculator page
- zero-cost, label-mismatch and default-region audits
- the savings-plan fallback for SKUs with no Reserved Instance

## What is not covered

**The browser harness is not exercised end to end.** It drives a live
third-party page whose DOM and prices change; asserting on it would produce a
suite that fails for reasons unrelated to this code.

That behaviour is instead captured in `reference/calculator-dom.md`, where each
of the 13 failure modes records the observed behaviour that justified the
workaround — including the measured numbers, such as a Fabric row pricing at
$30,013,020/month with the hours factor set wrong versus $41,308 correct.

The tests do assert that those guards are still present in `harness.js`, so the
documented protections cannot quietly disappear.

## Confidentiality

`test_no_customer_data` scans every file, and the fixture workbooks, for real
hostnames, GUIDs and credential patterns. It runs as part of the suite. The
repository is public — please keep real inventories, exports and estimates out
of it.
